# Unemployment Statistics Dashboard

## 📊 Project Overview

The **Unemployment Statistics Dashboard** is an interactive data analytics project built using **Power BI** to analyze unemployment patterns and trends.

The dashboard helps users understand unemployment based on factors such as **year, age group, and gender** through interactive charts and visualizations.

## 🎯 Objectives

* Analyze unemployment trends over different years
* Compare unemployment across different age groups
* Understand differences based on gender
* Identify patterns and changes in unemployment
* Present the data through an interactive dashboard

## 🛠️ Tools & Technologies

* Power BI
* Data Visualization
* Data Cleaning & Transformation
* Microsoft Excel / CSV
* Power Query

## 📈 Dashboard Features

* Year-wise unemployment analysis
* Age-group comparison
* Gender-based analysis
* Interactive filters and slicers
* KPI cards for key statistics
* Charts for identifying unemployment trends

## 🔄 Project Workflow

```text
Raw Dataset
     ↓

     ↓

     ↓

     ↓
Power BI Dashboard
     ↓
Interactive Insights
```
